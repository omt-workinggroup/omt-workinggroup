# OMT WORKING GROUP

A free digital library and AI-assisted learning platform for students. Find books, learn Microsoft Word, Excel, PowerPoint, Access and Outlook, download free templates, and ask **OMT AI** to find resources or explain difficult concepts.

Built with plain **HTML, CSS and JavaScript** (ES modules, no framework, no build step), plus one serverless function for the AI.

## Content approach: hybrid library

| Access label | What it means | Can you read/download here? |
|---|---|---|
| **On OMT** | Our own guides and templates (CC BY 4.0) | Yes, read on the site and download the DOCX/XLSX/PPTX |
| **Free & open** | Public domain or openly licensed (OpenStax, Project Gutenberg, MIT OCW…) | Read free on the official source |
| **Official source** | Free on the provider's own site (Microsoft Support, GCFGlobal, Harvard CS50) | Opens the official site |
| **Buy or borrow** | Copyrighted books | Description only, with links to Open Library to find an edition or borrow |

The site never hosts or links to unauthorised copies. Direct downloads exist **only** for files OMT owns, and an automated test enforces this.

## Run locally

You need Node.js 20 or later.

```bash
npm install
npm start            # http://localhost:8080  (AI assistant runs in demo mode)
```

Open the site through a web server, not by double-clicking the HTML files: browsers block `fetch()` on `file://` URLs, and the pages show a message explaining this.

To run the AI function locally too:

```bash
npm install -g netlify-cli
cp .env.example .env         # then add your ANTHROPIC_API_KEY
netlify dev                  # http://localhost:8888, with /api/ai live
```

## Configure the AI assistant

The assistant works in two modes:

- **Demo mode** (no API key): prepared explanations for about 20 common topics (VLOOKUP, IF, PivotTables, Word styles, mail merge, slide design, databases, study techniques, Python basics…), real catalogue search, and live Open Library search. Every demo answer is labelled *"Demo response: prepared answer, not generated by an AI model"*.
- **Live mode**: answers are generated by Claude through `netlify/functions/ai.mjs`, served at `/api/ai`.

To switch on live mode:

1. Create an API key at <https://console.anthropic.com>.
2. In Netlify: **Site configuration › Environment variables**, add `ANTHROPIC_API_KEY`.
3. Redeploy. The badge on the assistant page changes from **Demo mode** to **Live AI**.

Optional variables (see `.env.example`): `OMT_AI_MODEL` (default `claude-opus-5-5`), `OMT_AI_EFFORT` (`low` by default, which keeps answers fast and cheap), and `OMT_AI_RATE_LIMIT` (requests per visitor per 10 minutes, default 20).

How the function works:

- It validates every request: JSON only, at most 20 messages of 2,000 characters each, and body size capped at 32 KB.
- For each question it searches the OMT catalogue and Open Library **first**, then sends those results to the model. The model may recommend only those records, and the function drops any id that isn't in them, so it cannot invent books or links.
- The system prompt enforces the copyright rules: no unauthorised copies, no long quotations, no claims to have read text it wasn't given.
- It applies best-effort per-visitor rate limiting, returns consistent JSON errors, handles timeouts and provider errors, and never logs message content.
- The API key exists only in the server environment. It never appears in frontend code.

The AI provider is isolated in that one file, so switching providers later means changing only `ai.mjs`.

## Deploy (Netlify, recommended)

1. Push this repository to GitHub.
2. In Netlify: **Add new site › Import an existing project**, then pick the repo. The settings come from `netlify.toml` (publish directory `.`, functions in `netlify/functions`).
3. Add `ANTHROPIC_API_KEY` (optional, see above).
4. After the first deploy, enable **Forms** detection in Netlify. The contact and copyright-report forms on `about.html` use Netlify Forms, and submissions appear in the Netlify dashboard.
5. Set your real domain:
   - Update `BASE`/canonical URLs in the HTML `<head>` (search for `omt-working-group.netlify.app`).
   - Run `SITE_URL=https://your-domain node scripts/build-sitemap.mjs`.
   - Update the `Sitemap:` line in `robots.txt`.

Other static hosts (GitHub Pages and similar) work for everything except the AI function and the forms. The assistant then stays in demo mode automatically.

## Adding resources

Add an object to `data/resources.json`. The interface updates automatically.

```json
{
  "id": "unique-kebab-case-id",
  "title": "Title",
  "author": "Author or provider",
  "publisher": "Publisher",
  "year": "2024",
  "kind": "book | guide | template | tutorial | course",
  "category": "computer-science | business | study-skills | productivity | general | word | excel | powerpoint | access | outlook | presentations",
  "level": "beginner | intermediate | advanced",
  "formats": ["Online book", "PDF"],
  "accessType": "omt | open | official | paid | info",
  "license": "CC BY 4.0",
  "description": "One or two factual sentences.",
  "tags": ["search", "keywords"],
  "sourceName": "OpenStax",
  "sourceUrl": "https://… (official page)",
  "readUrl": "https://… (only for free, legal reading)",
  "downloadUrl": "assets/downloads/file.xlsx (OMT-owned files only)",
  "guide": "data/guides/id.html (OMT guides only)",
  "featured": false,
  "added": "2026-10-15"
}
```

Rules (checked by `npm test`): ids are unique, external resources need an `https` `sourceUrl`, `paid` books never get read/download links, and `downloadUrl` is allowed only for `omt` resources whose file exists.

Never invent metadata. Copy the title, author and year from the official source page.

## Testing

```bash
npm test               # unit tests: catalogue rules, search, demo AI, Markdown safety, AI function (mocked)
npm run test:e2e       # browser test: 13 pages × 6 widths (320–1440px), no overflow or console errors,
                       # search, filters, favorites persistence, downloads, mobile menu, assistant demo
npm run check-links    # checks every external link and local file in the catalogue (needs internet)
```

Run `npm run check-links` before each deploy. External sites change their URLs over time, and the "Link not working? Tell us" link on each resource page lets visitors report problems.

To regenerate the templates: `pip install openpyxl python-docx python-pptx && python3 scripts/build-templates.py`.

## What works now and what needs setup

**Works out of the box:** all pages and navigation, responsive layout and mobile menu, catalogue search with natural-language queries, filters, sorting, grid/list view, load more, resource details with related resources, OMT guides and template downloads, Office and Presentation centers, favorites (stored on this device), Open Library search, AI assistant in demo mode, dark mode, SEO metadata, sitemap and robots.txt.

**Needs configuration:** live AI answers (`ANTHROPIC_API_KEY` on Netlify), contact and copyright forms (Netlify Forms), your real domain in the canonical/sitemap URLs.

**Future ideas:** user accounts with synced favorites (the `js/core/favorites.js` interface is designed to be replaced by an API), learning paths, more languages, more original guides.

## Notes

- Favorites use `localStorage`. They are per-device and per-browser, and are not synced.
