These commands work on almost any Linux server, many network appliances and macOS. Type man command to read the manual for any of them.

Moving around and files

CommandWhat it does
pwdShow the current directory
ls -laList files, including hidden ones, with permissions and sizes
cd /var/logChange directory (cd .. goes up, cd ~ goes home)
mkdir -p a/b/cCreate directories, including parents
cp -r src dst / mv old newCopy (recursively) / move or rename
rm fileDelete. There is no recycle bin, so double-check before using rm -r
find / -name "*.conf"Search for files by name

Reading files and logs

CommandWhat it does
less fileScroll through a file (press q to quit, / to search)
tail -f /var/log/syslogFollow a log file live
grep -ri "error" /var/logSearch text recursively, ignoring case
journalctl -u nginx --since "1 hour ago"Read a service's logs on systemd systems

Processes and services

CommandWhat it does
top or htopLive view of CPU, memory and processes
ps aux | grep nginxFind a running process
kill PIDAsk a process to stop (kill -9 forces it)
systemctl status|restart nginxCheck or restart a service

Disks, users and permissions

CommandWhat it does
df -h / du -sh *Free disk space / size of each item here
chmod 640 fileSet permissions: owner read+write (6), group read (4), others none (0)
chown user:group fileChange the owner
sudo commandRun one command as the administrator

Networking

CommandWhat it does
ip a / ip rShow interfaces and addresses / the routing table
ping -c 4 8.8.8.8Test reachability
traceroute or mtr hostShow the path packets take
ss -tulpnList listening ports and the programs using them
dig example.comQuery DNS
curl -I https://example.comFetch HTTP headers from a server
ssh user@host / scp file user@host:/tmpLog in to / copy files to a remote machine

Archives

tar -czf backup.tar.gz folder/ creates a compressed archive and tar -xzf backup.tar.gz extracts it.

Practice

On any Linux machine: find the five largest items in /var/log with du -sh /var/log/* | sort -h | tail -5, then list the ports your machine is listening on.
