What's inside

  • Budget sheet — enter expected and actual amounts for income and each spending category.
  • Totals, the difference between planned and actual spending, and your remaining balance are calculated with SUM formulas.
  • Transactions sheet — log individual purchases with a date, description, category and amount. The Budget sheet totals each category with SUMIF.

How to use it

  1. Download the file and open it in Excel (it also opens in Excel for the web, LibreOffice Calc and Google Sheets).
  2. In Budget, type your planned monthly income and planned amount for each category in the Planned column.
  3. Through the month, add each purchase to Transactions. Use one of the category names exactly as written in the Budget sheet.
  4. Check the Actual and Difference columns. A negative difference means you overspent in that category.

Make it yours

Rename a category in both sheets to keep the SUMIF totals working. To add a row, insert it inside the existing table so the totals include it.
