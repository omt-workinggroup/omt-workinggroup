What a lookup does

A lookup finds a value in one table and returns related information from the same row. Example: you have a list of student IDs in one sheet and want each student's name from another sheet. Instead of copying names by hand, a lookup formula fetches them for you.

The example data

Sheet Students (A1:C5):

A: IDB: NameC: Course
2S101Ada OkaforEconomics
3S102Tunde BelloComputer Science
4S103Grace MensahLaw
5S104Musa IbrahimAccounting

On another sheet, cell A2 contains S103 and you want the name in B2.

VLOOKUP

=VLOOKUP(A2, Students!A2:C5, 2, FALSE)
  1. A2 — the value to look for (the ID).
  2. Students!A2:C5 — the table. The value you search for must be in the first column of this range.
  3. 2 — which column of the table to return (1 = ID, 2 = Name, 3 = Course).
  4. FALSE — exact match. Almost always use FALSE; TRUE means "approximate match" and requires a sorted first column.

Result: Grace Mensah.

XLOOKUP (Microsoft 365 and Excel 2021 or later)

=XLOOKUP(A2, Students!A2:A5, Students!B2:B5, "Not found")
  • Search column and return column are chosen separately, so the return column can be to the left.
  • Exact match is the default.
  • The fourth argument is what to show when nothing matches — no #N/A errors.

Lock your ranges before copying

When you fill a formula down, Excel shifts the ranges. Add $ signs to keep the table fixed:

=VLOOKUP(A2, Students!$A$2:$C$5, 2, FALSE)

Tip: select the range in the formula bar and press F4 to add the dollar signs.

Common errors

  • #N/A — the value isn't in the first column. Check for extra spaces (use TRIM) or numbers stored as text.
  • #REF! — the column number is larger than the number of columns in the table.
  • Wrong result — you probably left out FALSE, so Excel did an approximate match.

Practice exercise

Recreate the table above. On a second sheet, type the four IDs in column A, then use VLOOKUP to fill column B with names and column C with courses. Then type S999 and wrap your formula with IFERROR(…, "Not found") to handle the missing ID.
